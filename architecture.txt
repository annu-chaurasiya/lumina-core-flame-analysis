# 🔥 AI-Assisted Flame Analysis Platform (CV-First Architecture)

## 1. Objective

Build a web-based combustion analysis system that:

* Detects flame boundaries from video
* Computes physical metrics (area, speed, stability)
* Visualizes results interactively
* Allows future ML integration

---

## 2. System Overview

### Pipeline

User Upload → Backend Processing → CV Engine → Physics Engine → Data Storage → Visualization

---

## 3. Architecture Layers

### 3.2 Backend Layer (FastAPI)

**Responsibilities:**

* File handling
* Pipeline orchestration
* Serving processed data

**API Endpoints:**

* POST /upload
* POST /process
* GET /results/{id}
* GET /download/{id}

**Processing Flow:**

1. Save video
2. Trigger processing job
3. Store outputs
4. Return results

---

### 3.3 CV Engine (Core Processing)

**Tech:** OpenCV

#### Step 1: Frame Extraction

* Extract frames using OpenCV or FFmpeg

#### Step 2: Preprocessing

* Resize frames
* Convert to HSV
* Apply Gaussian blur

#### Step 3: Flame Detection (Thresholding)

* HSV range filtering
* Binary mask generation

#### Step 4: Post-processing

* Morphological operations (open/close)
* Noise removal

#### Step 5: Contour Detection

* Extract contours
* Select largest contour

#### Output:

* Binary masks
* Flame contours per frame

---

### 3.4 Physics Engine (Core Differentiator)

**Inputs:**

* Contours
* Frame rate
* Pixel-to-length scale

#### Computations:

1. Flame Area

* Area enclosed by contour

2. Flame Centroid

* Using image moments

3. Flame Speed

* Displacement of centroid over time

4. Perimeter

* Length of contour

5. Optional Metrics

* Curvature estimation
* Stability index

#### Output Format:

[
{"time": 0.01, "area": 1200, "speed": 0.5},
{"time": 0.02, "area": 1300, "speed": 0.6}
]

---
